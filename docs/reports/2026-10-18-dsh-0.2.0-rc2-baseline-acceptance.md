## 5. 测试集预期变更记录（基线重建修改日志）

版本化套件 `cases/dsh-cli-0.2.0-rc.2-baseline-v1.json` 相对 0.1.2 套件的修改及证据：

| # | 修改 | 原因 | 证据 |

| 1 | BOOT-007/008 的 `--patch` fixture 重写为顶层 YAML 数组（`- insert: - id: …`） | 0.2.0-rc.2 要求 patch 文件为顶层数组的 loader patch 条目，旧 map 格式 exit=1 | 实测报错 `must be a top-level YAML array of loader patch entries` |
| 2 | BOOT-007/008/009/010 增加 `env: {"DSH_HOME": "{tmp}/home"}` 隔离 | 0.2.0-rc.2 每次 `--dump-config` 会重写 `~/.dsh/profiles/web/cordis.yml`；无隔离时套件污染真实 profile（实测 cordis.yml mtime 被改为执行时刻） | 补隔离后 4 条用例全部通过且不再触碰真实 `~/.dsh` |
| 3 | PLG-002/004/005 错误文案期望 `pnpm failed` → `plugin command failed` | 0.2.0-rc.2 报错契约变更（更准确且附 diagnostics 日志路径），属改进 | 执行报告 `stderr_tail` 实测为 `dsh: plugin command failed; diagnostics: ...` |
| 4 | 执行环境加除噪前缀 `NODE_OPTIONS=--no-warnings all_proxy=` | Node v22 每次调用打印 UNDICI 实验警告（177B）；宿主 `all_proxy=socks5://…` 触发 dsh 的 SOCKS 告警（143B）。两者均为环境噪声 | 第一次全量运行的 8 条 failed 全部为 `stderr_empty` 断言被噪声污染（177/320 字符）；加前缀后同套件 0 failed。**两次运行的唯一环境差异即此前缀** |

补充环境变更：headless profile 默认模型由 `magpie-responses/codex-*`（429 额度尽）切换为 `deepseek-official/deepseek-chat`（`~/.dsh/profiles/headless/cordis.patch.yml`），Agent 行为套件与裁判均在 DeepSeek 后端下执行。
